# Worksheet Review: LOCATION vs EVENT

Total kandidat: **145** kemunculan standalone (Badr/Uhud/Khaibar/dst. tanpa kata "Perang" di depan).

**Cara isi:** untuk tiap baris, baca `kalimat_konteks`, lalu tentukan apakah maksudnya **tempat fisik (LOCATION)** atau **peristiwa perang (EVENT)**. Isi kolom `keputusan` di file CSV (`location_event_review.csv`). Kolom `usulan_heuristik` hanya petunjuk kasar dari kata-kunci, BUKAN keputusan.

Aturan ringkas (lihat `docs/anotasi_guideline.md`):
- **LOCATION** kalau menunjuk tempat: "menuju Badr", "di Khaibar", "sumur Badr", "penduduk Khaibar".
- **EVENT** kalau menunjuk peristiwa perangnya: "sepulang dari Badr", "kemenangan di Uhud", "pasca Hudaibiyah".
