## 1. Executive Summary

5 skenario SRL-NER yang dibandingkan:

| Skenario | Komponen | Hipotesis |
|---|---|---|
| **S1 — Baseline** | Fix THRESHOLD=0.9, tanpa class weight, tanpa contrastive, tanpa augmentation | Replikasi paper Ariyanto 2025, F1 target ≈ 0.863 |
| **S2a — SCL + Baseline** | S1 + Strict Supervised Contrastive Learning (Khosla 2020 / Dewabharata Eq. 2-3) | Representasi token sekelas lebih disiplin → F1 minoritas naik |
| **S2b — JSCL + Baseline** | S1 + Jaccard Similarity Contrastive (Dewabharata Eq. 4-6, sentence-level) | Variasi joint contrastive — Jaccard antar kalimat sebagai signal |
| **S3a — SCL + Augmentation** | S2a + Sentence-based augmentation kelas minor (Dai & Adel 2020 Mention Replacement) | Data + representasi → F1 EVENT tertinggi |
| **S3b — JSCL + Augmentation** | S2b + Sentence-based augmentation | Variant JSCL dengan augmentasi |
